Scanio `v0.1.0-alpha.1` is the first COM-scanner diagnostic preview for Windows 10/11 x64.

Included:

- passive Windows COM device discovery;
- explicit manual serial connection with configurable profile;
- byte-exact scan framing by terminator or silence timeout;
- persistent RAW/HEX evidence and transport chunk diagnostics;
- UTF-8, ASCII, Windows-1251, and Latin-1 decoding;
- EAN-13 validation and plain-text fallback;
- deterministic Disconnect and application-exit cleanup.

Known limitations:

- unsigned preview; Windows SmartScreen may warn;
- portable ZIP only, no installer;
- physical Datalogic/Zebra acceptance is not yet run;
- direct USB HID/POS and keyboard-wedge capture are not implemented;
- GS1 serialized-marking and IATA BCBP structured analyzers are not implemented;
- Notebook, History, persistence, export, localization switch, and automatic updates are not implemented;
- Windows is the only supported operating system.

Verify the downloaded ZIP against `SHA256SUMS.txt`. Scanio does not disable or bypass Windows protections.
