# Scanio v0.3.0-alpha.3

This prerelease adds a fully local Notebook, persistent History, clipboard copy, and diagnostic export to the existing Windows COM-scanner workflow.

Included:

- named recording sessions with Start, Pause, Resume, and Stop;
- independent persistence of every occurrence, including identical consecutive payloads;
- ordered background writes that do not block or interrupt scanner capture;
- SQLite storage for exact raw and payload bytes, chunks, framing, transport identity, decoded values, and all structured analyses;
- History with session reopen, rename, and confirmed cascade deletion;
- clipboard copy with visible scanner control-character labels;
- atomic UTF-8 TXT, RFC 4180 CSV, and structured JSON export;
- portable `Data/scanio.db` storage selected by the packaged `portable.flag`;
- clean Notebook queue flush before COM transport release on application exit.

Security and reliability notes:

- the SQLite native dependency is explicitly pinned to a non-vulnerable patch and checked by NuGet audit;
- exports preserve an existing target if writing fails;
- all persistence remains local, with no telemetry, accounts, synchronization, or online lookup.

Known limitations:

- unsigned portable Windows x64 package; SmartScreen may warn;
- physical Datalogic/Zebra, power-loss, and restart acceptance is still user-run on Windows hardware;
- direct USB HID/POS, keyboard-wedge capture, installer, automatic updates, in-app database backup, and repair are not implemented yet;
- Windows is the only application platform; portable domain, storage, and ViewModel tests run on macOS.
