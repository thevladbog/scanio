# Scanio v0.3.0-alpha.7

This prerelease fixes an application-shutdown hang discovered during physical COM-scanner testing of `v0.3.0-alpha.6`.

## Fixed

- Closing the main window can no longer wait indefinitely for a stuck serial-driver cleanup.
- Scanio still attempts a graceful scanner disconnect and port release first.
- If the driver does not return, the main window closes after a two-second grace period and the process is allowed to terminate.
- A late cleanup failure is observed in the background instead of becoming an unhandled task exception.

The shutdown deadline is covered by a deterministic regression test whose simulated driver cleanup never completes.

## Included from earlier feedback builds

- COM disconnect initiates handle closure before waiting for a pending serial read.
- Notebook buttons and export selectors vertically center their values.
- Header layout, logo sizing, primary-action contrast, and active-navigation indication include the earlier physical-feedback fixes.

## Still not included

- Keyboard-wedge scanner capture is not implemented yet.
- The Windows build is unsigned and may trigger a SmartScreen warning.

## Verification requested

- Connect the same scanner and initiate disconnect.
- While disconnect is still pending, close the Scanio window.
- Confirm that the process exits within approximately two seconds.
- Start Scanio again and report whether the same COM port can reconnect immediately or remains busy until the scanner is replugged.
