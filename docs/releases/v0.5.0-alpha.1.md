# Scanio v0.5.0-alpha.1

This unsigned Windows prerelease adds a focused keyboard-scanner test mode and refines the Monitor, Notebook, History, Russian interface, and display settings for continued field acceptance.

## Keyboard scanner mode

- The Connection screen can reconstruct scanner text delivered by Windows while Scanio's dedicated capture field has focus.
- Enter, Tab, or a short silence completes the reconstructed scan for diagnostic processing.
- This mode observes normal focused Windows text input. It is not raw USB capture, does not identify a scanner automatically, and does not replace direct HID/POS support.
- COM and keyboard capture remain explicit, mutually exclusive connection modes.

## Monitor, Notebook, and History

- Reopening Monitor selects the latest received scan so the current evidence is immediately visible.
- Monitor rows use plain numbering without the previous prefix glyph.
- Notebook and History visually group byte-identical occurrences, show their occurrence count, and retain the latest metadata for the grouped row.
- Copy and TXT, CSV, and JSON exports continue to preserve every recorded occurrence in order. Payloads with equal decoded text but different bytes remain distinct.

## Interface and display settings

- Russian labels, guidance, statuses, and primary actions were revised for clearer scanner-testing workflows.
- Primary actions use the revised graphite/light treatment, and Settings uses a flatter layout.
- Settings controls whether RAW control labels, HEX evidence, and transport chunks are shown, and switches list density between comfortable and compact rows.
- Language and display preferences continue to be stored locally.

## Release and privacy boundaries

- The package is `Scanio-0.5.0-alpha.1-win-x64-portable.zip` with a SHA-256 entry in `SHA256SUMS.txt`.
- The package is self-contained and intentionally unsigned. Windows SmartScreen may warn; Scanio does not disable or bypass Windows protections.
- Scan data, Notebook sessions, History, settings, and analysis remain local. Scanio has no accounts, cloud sync, telemetry, or automatic uploads.
- Direct raw USB HID/POS capture, automatic scanner identification, an installer, and automatic updates are not included.

## Acceptance still required

Windows CI passed the full solution, both Connection modes in Russian and English at 1440×900 and 1024×700, both density modes, Monitor with HEX/chunks enabled and disabled, focused WPF text plus Enter capture, the self-contained smoke launch, and the executable icon check. These automated gates do not replace physical scanner acceptance.

After publication, real Windows hardware acceptance remains **not run** until the user tests:

- a keyboard-wedge scanner with an Enter suffix;
- a keyboard-wedge scanner with a Tab suffix;
- a keyboard-wedge scanner completed by silence without a suffix;
- the available Datalogic COM scanner;
- the available Zebra COM scanner;
- repeat recording, Monitor navigation, display-setting changes, reconnect, port release, and occurrence-preserving exports on that hardware.

Automated, simulated, and rendered evidence must remain recorded separately from those physical results.
