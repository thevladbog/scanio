# Scanio v0.3.0-alpha.4

This prerelease replaces `v0.3.0-alpha.3`, whose portable executable terminated before displaying the main window.

Fixed:

- the WPF header-height resource now has the required `GridLength` type instead of a runtime-incompatible `Double`;
- the published self-contained Windows executable is launched for five seconds in CI after compilation;
- the release workflow runs the packaged portable executable before creating or uploading the ZIP;
- startup smoke failures include recent Windows Application and .NET Runtime event-log evidence.

Notebook and export capabilities remain unchanged from `v0.3.0-alpha.3`:

- named recording sessions with Start, Pause, Resume, and Stop;
- local SQLite History preserving exact scan evidence;
- clipboard copy and atomic TXT, CSV, and JSON export;
- portable storage in `Data/scanio.db` selected by `portable.flag`.

Known limitations:

- unsigned portable Windows x64 package; SmartScreen may warn;
- physical Datalogic/Zebra acceptance is still user-run on Windows hardware;
- direct USB HID/POS, keyboard-wedge capture, installer, automatic updates, in-app database backup, and repair are not implemented yet.
