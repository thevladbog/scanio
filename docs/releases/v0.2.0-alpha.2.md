# Scanio v0.2.0-alpha.2

This prerelease adds offline structured payload analysis to the existing Windows COM-scanner diagnostic flow.

Included:

- GS1 fixed- and variable-length application identifiers with parenthesized and raw GS/FNC1 forms;
- local serialized GS1 marking-data extraction for GTIN, serial, verification key, and crypto tail;
- conservative product-group candidates with explicit ambiguity and no network lookup;
- EAN-8, UPC-A, and EAN-13 check-digit validation;
- IATA BCBP mandatory fields, multiple legs, and safe partial/conditional-section diagnostics;
- absolute HTTP/HTTPS URL display without automatic navigation;
- Monitor presentation of all ordered analyzer results, fields, confidence, evidence, errors, and warnings.

Evidence boundary:

- payload format and physical barcode symbology remain separate;
- payload-only analysis never claims DataMatrix, QR, or another physical symbology as exact;
- Serialized marking results do not imply official online or cryptographic validity.

Known limitations:

- unsigned portable Windows x64 package; SmartScreen may warn;
- physical Datalogic/Zebra acceptance is still user-run on Windows hardware;
- direct USB HID/POS, keyboard-wedge capture, Notebook, History, persistence, export, installer, and automatic updates are not implemented yet;
- Windows is the only application platform; portable domain tests run on macOS.
