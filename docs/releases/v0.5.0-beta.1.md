# Scanio v0.5.0-beta.1

This unsigned Windows prerelease introduces a per-user installer alongside the existing portable package.

## Packages

- `Scanio-0.5.0-beta.1-win-x64-setup.exe` is the primary download. It installs without administrator access, offers an optional desktop shortcut, and installs Scanio for the current user.
- `Scanio-0.5.0-beta.1-win-x64-portable.zip` is the no-install alternative. Keep its `portable.flag` file and `Data/scanio.db` together with the extracted application.
- `SHA256SUMS.txt` contains one SHA-256 checksum for each package. Verify the checksum before running the selected package.

## Local data and security boundary

Installed Scanio data is stored in `%LOCALAPPDATA%\Scanio`. Uninstalling the application removes the installed program but retains that local data. The portable package keeps its local data in `Data/scanio.db` next to the extracted application.

This beta is intentionally unsigned. Windows SmartScreen may warn; Scanio does not disable or bypass Windows protections. Scanio has no automatic update mechanism.

## Acceptance still required

Windows CI verifies the packages and release contracts, but user-run physical hardware acceptance is still required. Test real keyboard-wedge, Datalogic, and Zebra scanners on Windows before relying on this prerelease in a production workflow.
