# Scanio v0.5.0-beta.4

This unsigned Windows prerelease provides a per-user installer and a portable package. It replaces the unpublished `v0.5.0-beta.3` packages. The beta.3 release workflow successfully verified the pinned Inno Setup compiler and proved that the installer refused a portable directory without modifying its data. It then stopped during the positive silent-install check because it launched the GUI installer directly and read its status through PowerShell's `$LASTEXITCODE`, which was empty for that executable boundary.

Beta.4 starts both the GUI installer and uninstaller through `Start-Process`, waits for each process to finish, and validates the captured process `ExitCode`. The package contents, install arguments, smoke test, retained-data check, uninstall check, and leftover-file check remain unchanged.

- `Scanio-0.5.0-beta.4-win-x64-setup.exe` is the primary download. It installs for the current user without administrator access and offers an optional desktop shortcut.
- `Scanio-0.5.0-beta.4-win-x64-portable.zip` is the no-install alternative. Keep `portable.flag` and `Data/scanio.db` together with the extracted application.
- `SHA256SUMS.txt` contains one SHA-256 checksum for each package. Verify the selected package before running it.

The installed application stores local data in `%LOCALAPPDATA%\Scanio`. Uninstalling removes application files and shortcuts but retains this local data. The portable package stores its database beside the application in `Data\scanio.db`.

The installer refuses a destination containing `portable.flag`, so it cannot silently overwrite a portable Scanio directory. Move or back up portable data before choosing a different empty installation directory.

This beta is intentionally unsigned. Windows SmartScreen may warn; Scanio does not disable or bypass Windows protections. Verify the SHA-256 checksum and confirm that the download came from the Scanio GitHub release before running it.

Scanio is local-only, has no automatic updates, and does not require a preinstalled .NET runtime. See the README for the complete feature and limitation list.

Windows CI verifies the packages and release contracts, but user-run physical hardware acceptance is still required. Test real keyboard-wedge, Datalogic, and Zebra scanners on Windows before relying on this prerelease in a production workflow.
