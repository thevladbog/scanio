# Scanio v0.3.0-alpha.6

This prerelease continues the physical Windows feedback cycle and replaces `v0.3.0-alpha.5` for UI verification.

## Fixed

- Button labels are vertically centered across the application, including the Notebook session and export actions.
- The selected export format is vertically centered in the closed selector.
- Export-format entries are vertically centered in the open selector.

The control alignment is enforced by the shared WPF theme and covered by a presentation contract test.

## Included from v0.3.0-alpha.5

- COM disconnect now closes the serial handle before waiting for a pending read, avoiding minute-long UI hangs with drivers that ignore read cancellation.
- The header layout, logo sizing, primary-action contrast, and active-navigation indication include the earlier physical-feedback fixes.

## Still not included

- Keyboard-wedge scanner capture is not implemented yet.
- The Windows build is unsigned and may trigger a SmartScreen warning.

## Verification requested

- Open **Notebook** and inspect the Start, Pause, Resume, Stop, Copy, and Export button labels.
- Open and close the export-format selector and inspect both the selected value and its TXT, CSV, and JSON entries.
- Recheck disconnect and immediate reconnect with the same physical COM scanner.
