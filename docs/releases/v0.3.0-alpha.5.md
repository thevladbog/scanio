# Scanio v0.3.0-alpha.5

This prerelease incorporates the first physical Windows feedback from `v0.3.0-alpha.4` and replaces that build for continued scanner testing.

Fixed:

- the application header now leaves enough vertical room for its navigation, context action, and complete Scanio logo;
- primary actions use the blue signal color instead of disappearing into dark panels;
- the active header destination has a persistent 4-DIP blue underline and semibold text;
- manual COM disconnect starts closing the serial handle before awaiting the processing loop;
- synchronous `SerialPort.Close` work runs outside the UI thread;
- drivers that ignore read cancellation until their serial handle closes can no longer deadlock the normal disconnect sequence.

Verification:

- 180 automated Release tests, including non-cancellable serial-read and close-order regressions;
- WPF Release compilation with warnings treated as errors;
- packaged Windows executable startup smoke before the portable ZIP is uploaded.

Physical retest requested:

- connect the same Datalogic or Zebra COM scanner used with `v0.3.0-alpha.4`;
- click **Disconnect** while the scanner is idle and confirm that the UI returns to **Disconnected** promptly;
- reconnect immediately and confirm that the COM port was released.

Known limitations:

- unsigned portable Windows x64 package; SmartScreen may warn;
- the serial disconnect fix still requires confirmation against the affected physical driver;
- direct USB HID/POS, keyboard-wedge capture, installer, automatic updates, in-app database backup, and repair are not implemented yet.
