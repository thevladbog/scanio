# Scanio v0.5.0-beta.5

This unsigned Windows prerelease provides a per-user installer and a portable package. It replaces the unpublished `v0.5.0-beta.4` packages. The beta.4 release workflow compiled both packages, proved that the installer refused a portable directory without changing its data, completed the positive installation and installed-mode launch checks, and ran the uninstaller successfully. Immediately after the uninstaller returned exit code 0, its transient self-deleting `unins000.exe` was still visible, so the strict leftover-file check correctly stopped publication.

Beta.5 adds a bounded post-uninstall cleanup wait for that Inno Setup self-deletion boundary. The workflow polls only its exact temporary installation probe using a monotonic stopwatch for at most 15 seconds. It still fails with the complete leftover list after the deadline, never recursively removes post-uninstall evidence, and removes the probe directory only when it is empty.

- `Scanio-0.5.0-beta.5-win-x64-setup.exe` is the primary download. It installs for the current user without administrator access and offers an optional desktop shortcut.
- `Scanio-0.5.0-beta.5-win-x64-portable.zip` is the no-install alternative. Keep `portable.flag` and `Data/scanio.db` together with the extracted application.
- `SHA256SUMS.txt` contains one SHA-256 checksum for each package. Verify the selected package before running it.

The installed application stores local data in `%LOCALAPPDATA%\Scanio`. Uninstalling removes application files and shortcuts but retains this local data. The portable package stores its database beside the application in `Data\scanio.db`.

The installer refuses a destination containing `portable.flag`, so it cannot silently overwrite a portable Scanio directory. Move or back up portable data before choosing a different empty installation directory.

This beta is intentionally unsigned. Windows SmartScreen may warn; Scanio does not disable or bypass Windows protections. Verify the SHA-256 checksum and confirm that the download came from the Scanio GitHub release before running it.

Scanio is local-only, has no automatic updates, and does not require a preinstalled .NET runtime. See the README for the complete feature and limitation list.

Windows CI verifies the packages and release contracts, but user-run physical hardware acceptance is still required. Test real keyboard-wedge, Datalogic, and Zebra scanners on Windows before relying on this prerelease in a production workflow.
