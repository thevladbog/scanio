# Scanio v0.5.0-beta.2

This unsigned Windows prerelease provides a per-user installer and a portable package. It replaces the unpublished `v0.5.0-beta.1` packages: that release workflow stopped before artifact creation because PowerShell 7 could not parse a numeric separator in a process-exit timeout. The timeout now uses PowerShell-compatible syntax and remains bounded at 10 seconds.

## Packages

- `Scanio-0.5.0-beta.2-win-x64-setup.exe` is the primary download. It installs for the current user without administrator access and offers an optional desktop shortcut.
- `Scanio-0.5.0-beta.2-win-x64-portable.zip` is the no-install alternative. Keep `portable.flag` and `Data/scanio.db` together with the extracted application.
- `SHA256SUMS.txt` contains one SHA-256 checksum for each package. Verify the selected package before running it.

## Local data and security boundary

Installed Scanio data is stored in `%LOCALAPPDATA%\Scanio`. Uninstalling the application removes the installed program but retains that local data. The portable package stores its local data in `Data/scanio.db` next to the application.

This beta is intentionally unsigned, so Windows SmartScreen may warn. Scanio does not disable or bypass Windows protections and has no automatic update mechanism.

## Acceptance still required

Windows CI verifies the packages and release contracts, but user-run physical hardware acceptance is still required. Test real keyboard-wedge, Datalogic, and Zebra scanners on Windows before relying on this prerelease in a production workflow.
