# Scanio v0.4.0-alpha.2

This unsigned Windows prerelease strengthens Notebook evidence export and makes analyzer validation messages useful during diagnosis.

## Notebook evidence

- Primary copy, TXT, and CSV exports preserve the barcode control characters received from the scanner exactly, including GS (`0x1D`).
- `Copy as readable text (<GS>)` and `Export readable TXT (<GS>)` explicitly render GS as `<GS>` so operators can inspect controls without changing the primary evidence copy.
- Duplicate counts now belong to the active Notebook session; a new session starts with its own count.
- Successful notebook feedback is turquoise and duplicate feedback is amber, each visible for 600 ms.
- Notebook and History actions use readable labels, with Windows layout checks covering their bounds at the supported window sizes.

## Diagnostic warnings

- Analyzer validation warnings now show the analyzer's concrete validation reason, so an invalid code can be investigated without guessing from a generic warning.

## Automated acceptance

- Portable Release suites cover capture, analysis, transports, application orchestration, storage, and Presentation ViewModels/contracts.
- Windows CI layout gates cover the WPF interface, including Notebook and History action visibility and bounds. This local macOS validation does not replace those Windows CI gates.
- The release package is unsigned and includes a SHA-256 checksum. Windows SmartScreen may warn.

## Physical acceptance still required

Automated and layout checks do not claim hardware acceptance. Retest this prerelease on Windows 10/11 with physical Datalogic and Zebra scanners, including exact-control scans, primary and readable copy actions, session duplicate counts, feedback visibility, COM discovery, reconnect, display scaling, and window close during a stuck disconnect.
