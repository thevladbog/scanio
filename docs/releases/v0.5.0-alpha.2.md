# Scanio v0.5.0-alpha.2

This unsigned Windows prerelease fixes the primary-action appearance and the COM connection action discovered during physical Windows acceptance of alpha.1.

## Fixed

- Primary actions now use a distinct blue fill with light text instead of disappearing into the dark status panel. The shared change covers Connect, Start test, Copy code, Notebook actions, and History actions.
- The COM action now changes from Connect to Disconnect after a successful connection and returns to Connect after disconnection.
- Every button in Connection, Monitor, Notebook, History, Settings, and the application header is required to use a reviewed shared style.
- Windows rendered tests verify the effective label contrast of every visible button in the existing language, viewport, density, and evidence matrix.

## Release and privacy boundaries

- The package is `Scanio-0.5.0-alpha.2-win-x64-portable.zip` with a SHA-256 entry in `SHA256SUMS.txt`.
- The package is self-contained and intentionally unsigned. Windows SmartScreen may warn; Scanio does not disable or bypass Windows protections.
- Scan data, Notebook sessions, History, settings, and analysis remain local. Scanio has no accounts, cloud sync, telemetry, or automatic uploads.

## Acceptance still required

Automated Windows tests and rendered evidence do not replace physical scanner acceptance. Real keyboard-wedge, Datalogic COM, and Zebra COM testing remains user-run on Windows, including reconnect, port release, repeat recording, and exact-control export scenarios.
