# Scanio v0.4.0-alpha.1

This prerelease is a complete C+ interface recovery based on the first physical Windows review. It replaces the earlier incremental UI fixes with one coherent, testable workspace for continued COM-scanner acceptance.

## Rebuilt interface

- A larger Scanio identity, stable header proportions, and an unmistakable active destination.
- Responsive Connection, Monitor, Notebook, History, and Settings workspaces at 1440×900 and the minimum 1024×700 window.
- Purpose-built scan and session lists instead of horizontally scrolling data grids.
- Long Datalogic and Zebra device names are constrained without pushing actions out of view.
- Shared buttons, selectors, and list rows vertically center their content and expose visible keyboard focus.
- Primary actions retain contrast on both paper and dark diagnostic surfaces.

## Working flows

- COM discovery remains passive; connecting is manual and only the selected port is opened.
- Disconnect availability follows the real connection state, and shutdown keeps its bounded two-second cleanup guard.
- Monitor keeps decoded payload, RAW, and HEX visible and provides one-click copy for the code, RAW, HEX, and diagnostic JSON.
- Notebook and History provide explicit copy-all, copy-unique, escaped-control, TXT, CSV, and JSON actions with state-dependent availability.
- Settings now persist language, monitor evidence options, follow-latest behavior, and list density.
- Russian and English switch immediately across navigation, workspaces, statuses, dialogs, analyzer narratives, and structured field names.
- `Scanio.exe` embeds the approved Scanio icon for Explorer, the taskbar, and window chrome.

## Automated acceptance

- Portable Release tests cover capture, analysis, transports, application orchestration, storage, and Presentation ViewModels/contracts.
- Windows CI builds WPF, renders all five destinations at 1440×900 and 1024×700 in Russian and English, checks visible actions and horizontal overflow, and uploads 20 PNG screenshots.
- Windows CI publishes the self-contained executable, compares its extracted 32×32 PE icon with the approved ICO frame, and performs a startup smoke test.
- The release package is unsigned and includes a SHA-256 checksum. SmartScreen may warn.

## Physical acceptance still required

Automated acceptance does not claim real scanner or driver acceptance. This build is specifically published for manual testing on Windows 10/11 with the available Datalogic and Zebra devices. Please verify COM discovery, connect, idle disconnect, immediate reconnect, scanning, all copy actions, Notebook, History, Russian/English switching, 100–200% display scaling, window close during a stuck disconnect, and Explorer/taskbar icon display.

Direct USB HID/POS and focused keyboard-wedge capture are not implemented in this prerelease. Linux and macOS application builds are also not included.
